## 架構

```
遊戲（iPad 網頁） ──GET──▶ 網頁應用程式 doGet ──讀──▶ 試算表（主題表、本週、說明）
                 ──POST─▶ 網頁應用程式 doPost ─加總─▶ 試算表「本週」那一週的那一列
```

- 網頁應用程式：執行身分＝阿葉（USER_DEPLOYING）、存取＝任何人含匿名（ANYONE_ANONYMOUS）。
- 授權範圍只有 `spreadsheets.currentonly`（只能碰綁定的這一張試算表）。
- 週次：台北時間（UTC+8）**週一 00:00 換週**；週 key＝該週週一日期 `YYYY-MM-DD`。
- 主題：「主題表」有寫那週就用（逐欄覆寫），沒寫就固定輪替 救援 rescue → 送貨 deliver → 釣魚 fish → 讀字 read → 收集 star，從 2026-10-12 那週開始。

### 讀取 GET
回應範例：
```json
{"ok":true,"w":"2026-10-19",
 "theme":{"key":"deliver","title":"送貨週","unit":"件","desc":"大家一起在彩虹配送站送出貨物","goals":[40,120,240]},
 "total":40,"reached":1,"plays":12,"cheers":[3,10,0,2],
 "prev":{"w":"2026-10-12","theme":{"key":"rescue","title":"救援週","unit":"隻","desc":"…","goals":[50,150,300]},"total":182,"reached":2},
 "paused":false,"now":1792000000000}
```
- `reached`：0＝還沒、1＝銅、2＝銀、3＝金。`prev` 是上一週結果；上一週早於 2026-10-12 時為 `null`。
- `paused`：暫停中仍可讀，前端可顯示「廣場休息中」。
- 快取 30 秒（數字最多慢 30 秒）。`now` 是伺服器現在時間（毫秒），前端可用來校正 iPad 時鐘。

### 送出 POST
- body 是 **text/plain** 的 JSON（避免 CORS 預檢）：`{"w":"2026-10-12","k":"goal","n":3,"i":"k3x9q0abcd"}`，**只能有 w、k、n 三個欄位＋選填的 i**，多一個別的就拒收。
- `i`（選填，2026-10-12 加）：這「一筆送出」的隨機代號，6–16 碼小寫英數。前端每筆新產生一個（不是裝置代號），**同一筆重送才沿用**；後端在鎖裡查 CacheService，6 小時內看過同一個 i 就只回 `{"ok":true}`、不再加——回應掉了（逾時、斷線）前端重送也不會算兩次。i 只放快取、不寫試算表。不帶 i 的舊前端照舊每次都加。
- `k` 種類與 `n` 範圍（整數）：`goal` 本週主題貢獻 1..10（2026-10-12 由 30 改 10；前端照這個分批）、`play` 開始一局 1..10、`cheer1`..`cheer4` 四種加油貼紙 1..3。
- `w` 必須是伺服器算出的「本週」。**換週寬限**：週一 00:00 之後 10 分鐘內，仍接受「上一週」的送出，算進上一週那一列（跨週邊界玩完的那一局不掉）；下一週永遠不收（前端應以 GET 回來的 `w` 為準，不要用 iPad 時鐘自己算）。
- 回應：`{"ok":true}` 或 `{"ok":false,"why":"..."}`

| why | 意思 | 前端怎麼辦 |
|---|---|---|
| bad_body / bad_json / bad_kind / bad_n | 格式錯 | 丟掉，不重送 |
| bad_week | 週次不對（多半是上週的舊資料） | 丟掉 |
| paused | 阿葉按了緊急暫停 | 丟掉或留著，之後再試 |
| rate | 全站這一分鐘太多（超過 120 次） | 留著，下次再送（同一個 i） |
| busy | 等鎖超過 8 秒 | 留著，下次再送 |
| no_sheet / auth / server | 後端問題 | 留著，下次再送 |

- 遞增用 LockService 鎖住「讀那一列→加→寫回」，不會因同時送出而遺失。
- 全站每分鐘上限 120 次（2026-10-12 由 1500 改 120；CacheService 計數，不分來源，因為我們本來就不知道來源；陀螺榜共用）。

## 隱私設計（送什麼、不送什麼）

- **送出的只有**：週次、種類、數量（例如「2026-10-12 這週、救援、3」）。
- **沒有**：裝置 ID、token、暱稱、個人成績、時間軌跡。Apps Script 的請求物件本來就沒有 IP 和標頭，程式結構上拿不到 IP。
- **試算表只存每週加總**，每週一列；唯一的時間是那一列的「最後更新（到分鐘）」。
- **不寫任何 log**：程式裡沒有 console/Logger；`exceptionLogging` 設成 `NONE`（錯誤不送到 Google Cloud 記錄）。
- Apps Script 平台本身會在編輯器的「執行作業」頁記下「哪個函式、幾點跑、成功或失敗」，不含請求內容或 IP（這是 Google 平台層，關不掉）。
- 讀取 GET 是公開的（任何人都能看到全島加總），這是刻意的：內容本來就是匿名總數。

## 怎麼改主題 / 目標

直接改試算表的「主題表」分頁（最多 1 分鐘生效；遊戲畫面最多再慢 30 秒）：

| 週次（週一日期） | 主題代號 | 標題（可空） | 單位（可空） | 銅 | 銀 | 金 | 說明（可空） |
|---|---|---|---|---|---|---|---|
| 2026-10-19 | fish |  |  | 60 | 180 | 360 |  |

- 主題代號只能填 `rescue` `deliver` `fish` `read` `star`；填錯就用當週的輪替主題。
- 銅銀金要是由小到大的正整數；填錯或空白就用該主題的預設值（救援 50/150/300、送貨 40/120/240、釣魚 60/180/360、讀字 150/450/900、收集 100/300/600）。
- 週次填非週一的日期會自動歸到那週的週一；同一週寫兩列以下面那列為準。
- 表上沒寫的週，照輪替自動帶。setup 已先填好 2026-10-12 起 5 週（＝預設值）。
- 已經結束的週不要再改（「上週結果」的銅銀金判定用的是主題表現在的值）。
- 目標調整原則（規格 §3）：之後依上週實際量的 70–80% 調。

## 緊急暫停

試算表「說明」分頁的「緊急暫停」打勾（命名範圍 `PAUSE`）→ 立刻不收任何送出（遊戲照常可以玩，只是不加總；陀螺榜也一起停收）；GET 仍可讀，並回 `paused:true`（最多慢 30 秒）。取消打勾就恢復。

## 全島陀螺榜（注音戰鬥陀螺，2026-10-12 加）

小朋友用注音拼出 5 個字的詞句，前端算戰力；擠得進全島前 5 名的詞句會送到這裡。阿葉決定：**自由輸入的詞句可以參加，但新進前 5 名的要阿葉勾「公開」才會上榜**。

### 阿葉怎麼審核（白話步驟）

1. 打開試算表（網址在最上面的表格），點下面的 **「陀螺榜」** 分頁。
2. 看「狀態」寫 **待審核** 的那幾列（表格會自動依戰力由高到低排）。
3. 每一句照下面的「審核清單」看一遍：
   - 沒問題 → 把那一列的 **「公開」打勾**。最多 30 秒後遊戲裡的全島陀螺榜就會出現（狀態欄會自動變成「公開」）。
   - 不想公開 → 把「狀態」改成 **不公開**（打字就好）。**不要刪掉整列**：刪了的話，下次有小朋友打一樣的字，它又會跑回來待審核。
   - 不確定 → 不用動。**待審核放 7 天會自動刪掉**，不會上榜。
4. 已經公開的想撤下來 → 把「公開」的勾取消（狀態會變「不公開」），最多 30 秒後從榜上消失。

**審核清單（有任何一項就不要勾公開）**
- 看起來像**人名、小名、暱稱**（例：某某寶貝、小明最棒、王小美啦）——小孩很常打自己或家人朋友的名字
- **學校、幼兒園、班級、地址、地名**（例：某某國小、幾號幾樓）
- **髒話**、罵人、不雅、諧音髒話（程式已擋常見的，但擋不完）
- **品牌、商品、藝人、網紅、卡通角色名**
- **政治、宗教**相關
- 看不懂、怪怪的、你不想讓別人家小孩看到的 → 一律不勾

### 「自動公開」開關

「陀螺榜」分頁第 2 列最左邊的勾選格（命名範圍 `TOPS_AUTO`）：
- **不勾（預設，建議）**＝新進前 5 名的詞句先「待審核」，要你勾公開才上榜。
- **勾起來**＝新進前 5 名的詞句直接公開、不用審核（等於把關交給黑名單）。只影響之後新送來的；已經在待審核的不會自動變公開。

### 分頁長相（第一次有人讀取或送出時自動建立；setup 重跑不會清資料）

| 列 | 內容 |
|---|---|
| 1 | 說明：勾「公開」才會上榜；請不要公開看起來像人名、小名、學校、地址的詞句 |
| 2 | A2＝自動公開勾選格（預設不勾）＋說明 |
| 3 | 審核清單（簡短版） |
| 4 | 表頭：詞句 ／ 戰力 ／ 狀態 ／ 公開 ／ 首次送出日期 |
| 5～ | 資料（程式每次寫入時依戰力重新排序、壓成連續的列；**表格下面不要寫別的東西**，會被當成資料整理掉） |

- 上不上榜**只看「公開」有沒有勾**；「狀態」欄是給人看的（`onEdit` 簡單觸發器讓兩欄自動一致：勾＝公開、取消勾＝不公開；狀態打「公開」會自動打勾）。
- 只存詞句、戰力、狀態、勾選、首次送出日期（只到日）。不存時間、裝置、IP、任何身分。
- 只保留戰力前 50 列（公開的前 5 名一定留）；「待審核」超過 7 天自動刪（有人送出時順便清）。
- 戰力一律由伺服器用公式重算（試算表裡的戰力數字改了也沒用，下次寫入會改回正確值）。

### 送出 POST（k:"top"）

- body：`{"k":"top","p":"宇宙強爸爸"}`，**只能有 k、p 兩個欄位**（前端算的戰力不收；多一個欄位就 `bad_body`）。
- 伺服器檢查：5 個字、每個字都在常用字表、不在黑名單、不是 `= + - @` 開頭（防試算表公式注入；寫進試算表的文字開頭若是這些字元一律前置 `'`）。
- 回應：`{"ok":true,"power":4643,"status":"pending"}`
  - `public`＝已在公開前 5 名（自動公開開著時，新進的也是這個）
  - `pending`＝擠得進前 5、等阿葉審核（前端顯示「審核後就會上榜喔！」）
  - `below`＝沒擠進前 5（**不存**）；被設成「不公開」的詞句再送也回 `below`
  - 「擠得進前 5」只跟**公開**的比：比它強或一樣強的公開詞句不到 5 句（一樣強時先來的排前面）。
  - 同一句重複送只算一筆（回目前狀態）。
- 錯誤 why（另加）：`bad_len`（不是 5 個字）、`bad_char`（有字不在常用字表）、`bad_formula`（公式開頭）、`blocked`（黑名單）→ 前端丟掉不重送。`paused` / `rate` / `busy` / `server` 同上表。
- 共用同一個鎖與每分鐘上限。

### 讀取 GET 的 tops

GET 回應多一個欄位 `"tops":[{"p":"宇宙強爸爸","power":4643}, …]`：只有**公開**的前 5 名、戰力高→低（戰力用公式重算；黑名單或不合格的就算被勾也不出現）。跟其他欄位一起快取 30 秒，所以勾公開後最多 30 秒生效（自動公開時，新進的那句會立刻清掉快取）。
「島上傳說」（`LEGENDS`）是前端內建的，後端不存。

### 戰力公式檔怎麼更新

`gas/TopsPower.gs`、`gas/TopsDict.gs` 由 `python tools/tops/build_gas.py` 從 `js/zhuyin-tops-power.js`、`js/zhuyin-tops-dict.json` 產生（同時寫到 `tools/tops/gas/` 和這裡）。前端公式或字典改了 → 跑 `build_gas.py` → `node test-core.mjs`（會檢查副本＝前端、抽 50 句比對戰力）→ 下面的部署步驟。沒重新部署的話，伺服器還是舊公式。

## 挑戰燈塔（爬塔代號）

挑戰燈塔爬 1–100 層，排行榜只列前 5 名。小孩不能自由打字，所以只能選 24 個固定代號（12 生肖＋12 星座），選了別人就不能選；**一週沒來＝代號釋出、紀錄歸零**。

**存什麼、不存什麼（白話）**
- 存：每個代號一列——「秘密碼的雜湊」（一串打亂後看不出原文的亂碼，秘密碼本人只在小孩的裝置上）、最高樓層、名次序號（誰先爬到，用來決定同樓層誰排前面）、到期日（只到「日」，＝最後一次活動日＋7 天）。
- 不存：每天登入的日期或任何時間戳、暱稱、IP、裝置資料、明文秘密碼。所有請求都是 POST，不用網址帶參數。
- 雜湊算法：`SHA-256("zy-tower:" + 秘密碼)`，小寫 hex。

**協定**（POST，text/plain 的 JSON，欄位必須剛好這些，多／少／型別不對＝`bad_body`）
- `{"k":"tw_claim","c":代號,"s":秘密碼}`：空的或已過期的代號 → `{ok:true,f:0}`；自己的 → 延長到期日、`{ok:true,f:目前樓層}`；別人用著 → `{ok:false,why:"taken"}`
- `{"k":"tw_ping","c":…,"s":…}`：是自己的且沒過期 → 延長到期日、`{ok:true,f}`；否則 `{ok:false,why:"lost"}`
- `{"k":"tw_score","c":…,"s":…,"f":1..100}`：新樓層＝`max(原本, min(f, 原本+20))`（一次最多 +20，超過夾住不拒收）；真的變高才換名次序號；`f` 不是 1..100 的整數＝`bad_f`
- `{"k":"tw_leave","c":…,"s":…}`：是自己的 → 清整列；不是也回 `{ok:true}`（不透露資訊）
- `c` 只能是這 24 個：rat 鼠、ox 牛、tiger 虎、rabbit 兔、dragon 龍、snake 蛇、horse 馬、goat 羊、monkey 猴、rooster 雞、dog 狗、pig 豬、aries 牡羊座、taurus 金牛座、gemini 雙子座、cancer 巨蟹座、leo 獅子座、virgo 處女座、libra 天秤座、scorpio 天蠍座、sagittarius 射手座、capricorn 摩羯座、aquarius 水瓶座、pisces 雙魚座。`s` 是 32 碼小寫 hex。
- 共用全站每分鐘上限（`rate`）、暫停開關（`paused`）、鎖（`busy`）；例外只回代碼。

**讀取**：GET 回應多一個 `"tower":{"board":[{"c":"leo","f":37}, …],"taken":["leo","rat", …]}`。`board` 最多 5 筆（沒過期且樓層>0；樓層高→低、同樓層名次序號小的在前），`taken` 是沒過期的代號。只有 c 與 f，不含雜湊、序號、到期日。claim／score／leave 讓榜或 taken 有變時會清掉 GET 快取，別人馬上看得到。

**到期怎麼處理**：沒有排程觸發器。claim／ping／score／leave 在鎖內順便把所有過期列整列清掉（含雜湊）；GET 讀榜時會濾掉過期的，發現有過期列就短暫等鎖（1 秒）順便清，拿不到鎖就算了。

**阿葉怎麼手動釋出代號**：開試算表「爬塔」分頁，找到那個代號那一列，把 **C～F 四欄**（秘密碼雜湊、最高樓層、名次序號、到期日）清空就好——別人馬上就能選，原本的人下次 ping／送樓層會收到 `lost`。**不要新增或刪除列**，也不用動 A、B 欄。

**部署注意**
- 「爬塔」分頁第一次用到時會自己建（setup、第一次的 POST／GET 都會建；固定 24 列）；不需要先手動跑 setup，但跑了也無妨（重跑不會動資料）。
- 沒用到新的 Apps Script 服務（只多用 `Utilities.computeDigest`），`appsscript.json` 的 scope 不用改，阿葉不用重新授權。
- 部署前先 `node test-core.mjs` 全過。下一個版號是 v4（v1＝同樂廣場、v2＝加陀螺榜、v3＝送出代號 i 防重複計數；v4＝挑戰燈塔）。
- 測試（W 段）：欄位／型別／代號／秘密碼／f 驗證、雜湊＝SHA-256、claim／ping／leave／score 各種情境、過期（到期日當天仍有效、隔天釋出且整列清掉）、+20 夾住與序號、doGet 的 tower（前 5、排序、排除過期與 f=0、不含雜湊）、暫停／上限／鎖、手動清空釋出。

## 已知風險 / 待確認

1. **網頁應用程式裡拿不拿得到「目前試算表」**：Google 官方文件寫綁定腳本在網頁應用程式情境下 `getActiveSpreadsheet()` 不可用，但社群普遍回報可用。若授權後 smoke 測試回 `{"ok":false,"why":"no_sheet"}`：把 `appsscript.json` 的 scope 改成 `https://www.googleapis.com/auth/spreadsheets`（程式已內建改用試算表 ID 開啟的備援），`clasp push`＋`clasp deploy -i …`，阿葉再授權一次（同意畫面會變成「所有試算表」，範圍比較大）。
2. **寫入速度**：每次送出要排隊拿鎖，一秒大約只能處理幾筆。前端要「一局結束合併送一次」、`busy` 時留著下次送。
3. **防灌只擋得到「單次加很大」與「全站爆量」**；有人寫程式慢慢灌擋不住，後果只是目標提早達成（規格已接受）。
4. **CORS**：預期 GET 與 text/plain POST 都能從 GitHub Pages 讀到回應（Apps Script 轉址到 googleusercontent 會帶 `Access-Control-Allow-Origin: *`）；要在前端開工時用瀏覽器實測一次。
5. 2026-10-11 測試時在阿葉的雲端硬碟留下一個不需要的小專案「plaza-probe-暫時測試可刪」（已取消部署、網址已失效；clasp 沒有刪檔權限）。可以直接在雲端硬碟刪掉。
6. **陀螺榜測試資料**：2026-10-12 線上實測送了一筆「宇宙強爸爸」（狀態待審核、沒公開，不會出現在榜上）。可以直接在「陀螺榜」分頁刪掉那一列，或放著 7 天後自動刪。
