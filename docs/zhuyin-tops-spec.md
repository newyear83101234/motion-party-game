# 注音戰鬥陀螺（詞句陀螺大亂鬥）規格

> 2026-10-12 凌晨 Claude 依阿葉想法設計（阿葉睡前交辦，分歧由 Claude 決定、早上報告，★＝阿葉可改）。
> 阿葉原話：「讓小朋友隨意輸入一個詞句，總共要 5 個字，用注音寫出來，比方說『宇宙強爸爸』『超級賽亞人』…這 5 個字就會變成像是戰鬥陀螺那樣下去進行戰鬥…看哪一個詞句才是最強的戰力，說不定是『努力小紅帽』還是『紅色翹翹板』…很無厘頭的風格」「不希望每一次都要利用算力」「排行榜前 5 名文字組合＋戰力數值，至少要到 999」「設個門檻，集滿多少貼紙或星星才可以玩一次，先收集再玩，保留驚喜感」。
> 參考：https://lpm1.live/「姓名戰鬥陀螺」——每個字變一顆陀螺，字形決定重量/穩定/攻擊/防禦，canvas 競技場碰撞旋轉，純前端。

## 1. 一局怎麼玩
1. **拿券**：每累積 ★15 顆星星（任何遊戲拿到的星星都算）＝1 張「陀螺券」，最多存 3 張；**第一次免費**（先讓孩子知道好玩）。沒券時入口顯示「再拿 N 顆星星就能玩」。不扣既有的星星罐/金幣，跟扭蛋經濟分開。
2. **打字（學注音的核心）**：畫面下方是大顆注音鍵盤（37 個符號＋四個聲調鍵＋輕聲＋⌫），一次拼一個字：拼好 → 出現候選字（最常用的在前，附注音；預設選第一個，可點別的）→ 確定 → 換下一格。5 格都填好才能「下場！」。每格字上方顯示注音。
   - 也提供「🎲 隨機靈感」：從內建無厘頭詞庫抽一個（例：宇宙強爸爸、超級賽亞人、努力小紅帽、紅色翹翹板、勇敢小兔子…），讓還不會拼的小孩也能玩。
3. **變身**：5 個字依序「叮」一聲變成 5 顆陀螺（字印在陀螺頂面），顯示每顆的四項能力與整句「戰力」。
4. **對戰**：對手＝排行榜上的詞句或內建「島上傳說」陀螺隊。5 回合一對一（第 1 字對第 1 字…），先贏 3 回合獲勝。競技場（碗形場地）裡兩顆陀螺自動旋轉、碰撞、火花、慢慢減速，先停或被撞出場的輸。
5. **結算**：勝負＋整句戰力＋「新紀錄！」；戰力夠高就上排行榜（見 §4）。

## 2. 能力值（確定性、不用算力）
- 同一個字永遠得到同一組能力（不靠亂數）：把字用固定字型畫到 64×64 離屏 canvas，量：
  - **重量**＝墨水像素比例（筆畫越多越重）
  - **穩定**＝左右/上下對稱度＋重心靠中
  - **攻擊**＝筆畫邊緣量（輪廓周長/尖角多）
  - **防禦**＝墨水分佈的緊密度（凸包填滿率）
  各自正規化到 1–99。注意：不同裝置字型不同會讓能力不一致 → **改用離線預算的能力表**：建置時用固定字型（Noto Sans TC）算好常用字（約 4000～5000 字）的四項能力存成資料檔；表外的字用字碼雜湊後備。這樣 iPad/電腦/伺服器算出來一定一樣。
- **單字戰力**＝重量×1.2＋穩定×1.0＋攻擊×1.3＋防禦×1.1 換算到 100–1999。
- **整句戰力**＝5 字總和＋組合加成，上限 **9999**（★）；常見範圍約 3000–6500，8000 以上很稀有。
  - 組合加成（讓小孩有「發現秘密」的樂趣，數字★可調）：疊字（爸爸、翹翹）＋200；押韻（5 字中有 3 字同韻母）＋300；同聲調連發（3 字以上同聲調）＋250；有動物字＋150；有顏色字＋150；有「超、強、王、神」之類的強字＋100（每句最多一次）。加成在結算列出（「疊字加成！」）。
- 排行榜與伺服器都用同一套公式（伺服器重算戰力，不信任前端送來的數字）。

## 3. 對戰模擬
- 2D 物理（俯視碗形場地，向心力往中間拉），渲染用 Three.js（跟小島同畫風：圓錐陀螺、字貼在頂面、碰撞火花、慢動作最後一擊），或 2D canvas 擬 3D——實作者擇一，畫面要精緻。
- 能力影響：重量＝質量、穩定＝轉速衰減慢、攻擊＝碰撞時給對方的推力、防禦＝被撞時的抵抗。
- **確定性**：亂數種子＝兩個詞句的雜湊，同樣的對戰每次結果一樣（大家說「宇宙強爸爸打得贏超級賽亞人」才會一致）。
- 每回合最長約 12 秒（超時比剩餘轉速）。小孩可以點「⏩ 快轉」。

## 4. 排行榜

> **★最終決定（10-12 凌晨，阿葉本人）**：「這個問題不用擔心，直接照原本版本做就好」→ 採用下方**原設計**（自由輸入＋前 5 名新詞句待審核、阿葉在試算表「陀螺榜」勾公開；試算表另有「自動公開」開關預設關）。後端已實作（tools/plaza/gas/Code.js，審核步驟見 tools/plaza/README.md）。下面方案 A 段落僅留紀錄。
>
> ~~10-12 凌晨更新~~（已被阿葉推翻）：米卡莎（兒少隱私）判下面原設計 FAIL——5 字詞句很容易是「小孩名字＋稱號」，人工審核也審不出只有家長才認得的小名，公開後被截圖也收不回。改採她推薦的**方案 A**（Claude 代決，早上報告阿葉）：
> - 自由輸入照常（玩、變身、對戰都行），但只進**「我家排行」**（本機前 5 名，永不上傳）。
> - **「全島陀螺榜」只收整句能完全切成「內建詞庫」片段的詞句**（js/zhuyin-tops-words.js，事先審過、以 2–3 字詞為主，不含姓氏/常見小名/地名/學校/品牌/藝人/政治/宗教）→ 從根本上不可能是人名，**不需要阿葉審核**；後端用同一份詞庫重驗。
> - 只有可上全島榜且戰力可能進前 5 的才送出（只送詞句本身）；伺服器只存榜上前 N 名的詞句＋戰力，不存時間/身分。
> - 家長頁說明＋可關閉上傳。若阿葉想要「自由詞句審核後公開」，米卡莎的條件清單見 scratchpad 報告（預設關閉、待審 7 天刪、人名樣式攔截、審核白話清單）。
>
> 以下為原設計（保留供參考）：
- 全島「陀螺榜」前 5 名：詞句（國字＋注音）＋戰力。另外固定顯示「你的最強詞句」（只在本機）。
- 後端沿用同樂廣場的 Apps Script（同一張試算表新增「陀螺榜」分頁）：前端送 `{k:"top", p:"宇宙強爸爸"}`，伺服器用同一公式重算戰力。
- **兒少安全**（自由輸入的詞句可能是小孩名字或不雅字）：
  - 只收 5 個國字、而且每個字都在常用字表內；擋髒話/不雅字黑名單。
  - **會進前 5 名的新詞句先進「待審核」**，阿葉在試算表勾「公開」才上榜（只有擠進前 5 的才需要審，量很少）；待審期間送出的那台裝置本機先看得到「審核後就會上榜喔」。
  - 不存任何身分、裝置 ID、IP；只存詞句、戰力、時間。
  - 一開始榜上是內建「島上傳說」（阿葉舉的例子），讓榜不會空著。
- 若兒少審查判定公開榜仍不妥 → 改成「本機排行＋島上傳說榜」，公開榜做成開關等阿葉決定。

## 5. 入口與存檔
- 小島入口：歸仁區「陀螺競技場」（★位置可調），卡片選單也有一張卡。
- 存檔 `zy{n}_tops = {tickets, starsBank, freeUsed, best:{p,power}, history:[最近 10 句]}`；備份碼帶上。
- 配音：教學、鍵盤提示（「先選一個符號」「選好了就按確定」）、變身、開戰、勝負、加成名稱等固定台詞預錄；不唸小孩打的字（避免機器音念奇怪組合）——但可以點陀螺聽單字發音（只限常用字表有預錄的字，沒有就不出聲）。

## 6. v2（10-13 阿葉）：五個字合體成一顆陀螺、三戰兩勝、競技感

> 阿葉原話：「5 個注音選出來後，會有一個轉場動畫合體變成一顆陀螺，再由這個陀螺下去對戰 3 戰兩勝或者比分數，不是用每一個字都單獨下去比」「兩顆陀螺顏色要不一樣比較好區分」「戰鬥畫面太溫和了沒有刺激感…要有競技的感覺」。上面 §1.3–1.4、§3 的「5 顆陀螺、5 回合一對一」由本節取代；打字、券、蛋、排行榜、戰力公式不變。規格總表：docs/zhuyin-v7-plan.md §1。

**6.1 合體轉場**（js/zhuyin-tops.js 的 st.fuse 狀態機，遊戲時鐘約 3.1 秒）：五顆小陀螺（藍隊色、各帶一個字）一顆一顆「叮」跳出來、下面是每個字的能力卡 → 飛到中間繞圈、越轉越快越飄越高 → 白光一閃＋震動＋「合體！」（tp_fuse）→ 一顆大陀螺（頂面一圈五個字＋注音，中間隊伍色星星，頂蓋邊五顆寶石）；五張能力卡飛到中間收成一張「合體陀螺」卡。這次開頁第二次起畫面下方有「點一下跳過」。之後照舊：戰力數字、加成徽章（合體卡上觸發的字發光、標出 ⚔️+10，合體陀螺換金色光圈）→ 紅隊合體陀螺從天上掉進碗裡。

**6.2 合體能力**（js/zhuyin-tops-sim.js 的 fuseStats；只影響對戰，戰力公式 zhuyin-tops-power.js／後端 TopsPower.gs 不動）：五個字含加成的能力合成一組 ——
重量＝0.75×平均＋0.25×最重、穩定＝0.7×平均＋0.3×最不穩（最弱的一環拖累）、攻擊＝0.6×平均＋0.4×最兇（帶頭衝）、防禦＝0.75×平均＋0.25×最硬；再以 50 為中心放大 1.6 倍、限 1–99（不放大的話五字平均把差異磨平）。合體陀螺半徑 ×1.7（大顆、常互撞、撞出場多）。

**6.3 三戰兩勝**（simulateMatch）：每回合 ROUND N（第 3 回合＝「決勝回合！」）→ 兩顆浮在碗上 → 3、2、1（tp_count）→「發射！」（tp_launch）掉進碗裡 → 撞到一方耐力（轉速）歸零或被撞出場。每回合種子＝兩句詞句（照字典順序）＋回合號的雜湊 → 同樣兩句永遠一樣、A 打 B＝B 打 A、三回合過程不同。tools/zy-test/tops.js 用 3000 場隨機詞句驗：戰力差 1000 以上強的一方約 8 成 5 贏、250–1000 約 7 成、250 以內約 5–6 成（不是必勝）。

**6.4 競技感**：小孩＝藍隊（#2ab4ff）、對手＝紅隊（#ff5626），陀螺、腳下光圈、碗裡名字牌「藍隊／紅隊」、上方名字牌外框、耐力長條（%）、得分點都用隊伍色。撞擊強度看這一下兩顆一共被扣多少轉速：輕／中／重 → tp_clash1/2/3、金黃＋兩隊色火花、兩顆都噴碎片（InstancedMesh 方塊，最多 150 塊輪流用，掉進碗裡停一下再縮掉；被撞得慘的那顆噴比較多）、衝擊圈、白光、鏡頭震動；中擊停格 0.05 秒、重擊停格 0.12 秒＋鏡頭往撞擊點推近＋整個畫面閃白光。兩顆貼著轉時一直冒小火花。決勝那一擊慢動作（原本就有）。回合結束「撞出場！／停下來了！」→「藍隊勝！／紅隊勝！」（tp_round＋贏了 tp_cheer）、得分點填色；整場「勝利！」（tp_victory）或「再接再厲」。背景音樂：合體起＝battle（manifest bgm.battle），回打字畫面換回 road。減少動態（prefers-reduced-motion）：震動兩成、鏡頭不推近、白光最多 0.25、碎片少一點。

**6.5 段位＝對手難度**：新手 → 銅牌 → 銀牌 → 金牌 → 彩虹（存檔 `zy{n}_tops.rank` 0–4，備份碼帶上；贏一場升一段，輸了不降）。對手從全島榜＋島上傳說＋骰子詞庫裡挑「戰力最接近 我的戰力×倍率」的 3 隊之一：新手 0.82、銅 0.92、銀 1.0、金 1.06、彩虹 1.12。第一次免費那場、輸了換對手：照舊先模擬挑會贏的（合體後很弱的句子幾乎每隊都打不贏 → 先找正式種子會贏的，都沒有才換一組種子 salt 1–11，同樣確定性；只有這兩種安慰場會用）。升段時大字「升段！🥉 銅牌」＋配音「升段了！現在是銅牌！」；結算比分旁顯示段位（升段有 ⬆️）。主程式 js/zhuyin.js 的 topsRankLabel()（→「🥉 銅牌」）給小島介紹卡顯示目前段位。
