→ 集章卡✅、罐子顯示「再 X 顆星」✅、稀有度改成**扭蛋抽獎**（機率與獎品由 Claude 設計）、新增小象／小恐龍／小鯨魚／彩虹小龍（3D 方塊畫風）✅、每日時間提醒❌。

## 底線（不可違反）
- 不花錢、沒有任何購買或廣告；扭蛋幣**只**能靠學習取得
- 永不倒退：不扣星、不扣寵物、寵物不會餓、不會難過、不會離家；集章卡不要求連續、不歸零
- 重複的獎品不浪費（自動換成點心）
- 有保底（運氣再差也一定拿得到稀有、超稀有）
- 機率公開：家長設定頁看得到；寵物圖鑑列出全部寵物剪影
- 開扭蛋沒有「差一點就中」的捉弄演出：膠囊顏色一出來就是結果

## 集章卡
每天第一局玩完（任一遊戲）蓋 1 格，最多 1 格/天；7 格換 1 枚 🌟金幣，卡片重置，可以一直集。不要求連續天數。

## 扭蛋機（小島上一棟建築，點它開扭蛋畫面）
**機率（每抽）**
| 稀有度 | 膠囊顏色 | 機率 | 內容 |
|---|---|---|---|
| 普通 | 藍 | 70% | 小島裝飾（長椅、花圃、路燈、小雕像、旗子、樹…，會自動放到小島上）或「點心包 +10」 |
| 稀有 | 紫 | 25% | 稀有寵物蛋（見寵物表），或寵物裝扮（帽子、蝴蝶結、披風） |
| 超稀有 | 金 | 5% | 超稀有寵物蛋：小恐龍、小鯨魚、彩虹小龍 |

**保底**：連續 4 抽沒有稀有以上 → 第 5 抽保證稀有以上；連續 14 抽沒有超稀有 → 第 15 抽保證超稀有（而且優先給還沒有的）。🌟金幣抽出的至少是稀有。
**不重複優先**：抽到寵物時，優先給還沒收集到的那隻；全部收齊才會重複（重複＝點心 +20）。
**節奏估算**（每天約 6 局、14 顆星）：每天約 1.4 抽；第一週約 2–3 隻新寵物；約 3 週內一定拿到第一隻超稀有。

**演出**（全程 ≤ 8 秒，點一下可以加速）：投幣 → 小孩轉把手（點或轉）→ 膠囊掉下來（顏色＝稀有度，金色有光）→ 點膠囊打開 → 獎品登場。寵物是一顆蛋，接孵蛋儀式：搖、裂、破殼、登場唸名字。

## 寵物進化（v7，2026-10-13；docs/zhuyin-v7-plan.md §2）
阿葉原話：「寵物進化可以做。進化特效可以參考數碼寶貝的進化特效那樣，會旋轉，然後有一個酷炫特效進化音樂」

**誰能進化**：已經「超級」（第 3 階段）的寵物，再集滿**進化能量 100** → 進化成「超級＋名字」（超級小象）。進化不會退回去。
**能量**（js/zhuyin-rewards.js `EVO_GAIN`，只加給「夥伴」，而且夥伴要已經超級、還沒進化；不是的話這次不加，也不存起來）：

| 來源 | 能量 | 在哪裡算 |
|---|---|---|
| 一般遊戲第 3 級以上拿 3 星（暖身局不算） | +10 | 結算（zhuyin.js evoAfterRound） |
| 每天第一次餵點心（結算的點心、扭蛋點心包／重複寵物換點心） | +5 | 結算、扭蛋（`evoFeedDay`；夥伴不能集的那天不算用掉） |
| 挑戰燈塔第一次到新樓層（每層） | +2 | 爬塔存檔接點（`evoTower`：記最高樓層，舊存檔第一次對不補發；放棄名字樓層歸零也不重算） |
| 第一次打倒某隻守塔怪 | +40 | 爬塔給扭蛋幣的接點（towerGive 的 coins） |

節奏估算：每天玩 3 星第 3 級 2–3 局＋餵點心 ≈ 25–35 點 → 約 3–4 天進化一隻；爬塔打倒一隻守塔怪就是 40。

**能量滿了**：回小島時選單出現「✨ 進化！」膠囊（寵物頭像）、3D 小島上那隻從寵物公園出來走、頭上一顆會跳的 ✨、貓頭鷹「XX好像要進化了！」（45 秒內不重講）；結算／扭蛋剛好集滿也唸一次。點膠囊、點 ✨、點那隻寵物、或圖鑑能量條的「✨ 進化！」→ 看進化演出。遊戲中、爬塔中不會跳出來。
**進化演出**（js/zhuyin-evolve.js，DOM＋CSS＋一張 canvas，不開 three.js）：對齊進化曲 `evolve`（22 秒、第 8.0 秒高潮）——
0 秒 暗場＋數位格線／光帶＋蓄力音效 → 0.9 秒浮起、光環出現 → 2.3 秒開始旋轉（越轉越快，每秒 0.5→7 圈）＋注音碼雨 → 4.7 秒變成發光剪影、字幕＋配音「小象進化——」→ 7.9 秒白光爆開（8.0 秒全白，震動、衝擊圈）→ 8.25 秒新外型亮相（背光放射、星星徽記、閃光、彩帶）→ 8.75 秒橫幅「超級小象！」→ 10.4 秒「🎉 太棒了」。
第一次一定完整看；看過一次之後點一下畫面＝直接跳到白光爆開（進化曲淡出）。減少動態（系統設定）＝不轉、不震、沒有碼雨、白光弱一點，時間照樣對齊音樂。背景音樂關著＝不放進化曲（音效照放）。
**進化後的樣子**：3D＝超級的 1.15 倍（原尺寸約 1.32 倍）＋腳下兩圈光環＋繞身體往上飄的光點＋頭上轉圈的金色星星（進化徽記）＋身體顏色加亮；2D 圖鑑＝金色卡、圖後面一圈慢慢轉的光、左上角星星徽記、名字「超級XX」、階段寫「進化」。
**圖鑑**：超級的夥伴（或還有能量的）卡片下面一條能量條「💫 40/100」＋右邊「進化後的剪影」（發光黑影＋小星星＝目標）；滿了變「✨ 進化！」可以直接點。**家長頁**：扭蛋機那段多一段進化規則（從 `EVO_GAIN` 產生）＋目前夥伴的能量、已進化名單。
**存檔**：`rewards.evo = { e: {寵物: 能量}, done: [已進化], day: 最後一次每日餵點心加能量的日期, tb: 爬塔最高樓層記號（-1＝還沒對過）, seen: 演出看過一次 }`，`cleanRewards` 清洗（能量 0..100、只留已收集的超級寵物），備份碼一起帶。演出**開始前**就存成已進化（中途關掉頁面也不會白集）。
