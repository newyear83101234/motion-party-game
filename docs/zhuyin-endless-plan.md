# 注音小島 v9：兩款「一局玩 10 分鐘以上」的新遊戲（2026-11-01）

阿葉原話（11-01）：「再幫我多新增兩款遊戲，要可以讓小朋友玩得比較久、能持續一直玩，並且會逐漸增加難度之類的，最好一場可以玩到 10 分鐘以上。你去思考一下，然後直接開始製作。」

## 0. 為什麼是這兩款

現有遊戲多是「一回合 5–8 題、1–2 分鐘就結算」，再長的是泡泡（一關一關）和爬塔（一層一層換遊戲）。
要「一直玩、越來越難、一局 10 分鐘」，最穩的是小孩本來就會玩很久的兩種格式：

| | 🏃 跑跑大冒險 | 🐟 小魚長大記 |
|---|---|---|
| 參考的格式 | 無盡跑酷（地鐵跑酷那種） | 大魚吃小魚 |
| 操作 | 左右滑／點左右半邊換跑道 | 手指拖到哪、魚游到哪 |
| 節奏 | 系統帶著跑（有時間壓力） | 自己慢慢游（沒有時間壓力） |
| 長久玩的動力 | 跑更遠、換風景、收金幣 | 一直長大、進化成更大的海洋動物、吃掉原本會咬你的魚 |
| 畫面 | 3D（three.js，夥伴下場跑） | 2D 畫布（自己畫的魚） |

兩款刻意一快一慢、一個被帶著跑一個自己決定，跟現有遊戲都不重複（音樂島的音符接接樂是「接掉下來的東西」，也不撞）。

## 1. 兩款共通的規則

- **無限玩**：一局不分回合，一直玩到心用完（或按 ⏸ 離開）。
- **區域**：每 60–90 秒過一區，畫面換主題、題目升一級、速度快一點；過區有慶祝＋補 1 顆心（最多 3）。
- **題目階梯（6 級，兩款共用 js/zhuyin-endless-core.js）**
  1. 聲母（ㄅㄆㄇ…，選項彼此差很多）
  2. 聲母＋長得像／聽起來像（ㄅㄆ、ㄉㄊ、ㄋㄌ、ㄓㄗ…）
  3. 韻母（含ㄧㄨㄩ，ㄢㄤ、ㄣㄥ 這類會出現）
  4. 拼音：一個字（聽「貓」選ㄇㄠ）
  5. 聲調：同一個音不同聲調（聽「馬」選ㄇㄚˇ／ㄇㄚˊ／ㄇㄚˋ）
  6. 兩個字的詞（聽「蘋果」選ㄆㄧㄥˊ ㄍㄨㄛˇ）
  - 第 1–2 級唸注音本身（已錄好），第 4–6 級唸國字（詞庫已錄好）＝不用新錄音就能出題。
- **自動調整（防挫折、讓玩得久）**：連錯 2 題 → 題目退一級＋速度慢一點，畫面區域照走（小孩不會覺得被降級）；之後連對 3 題再升回來。
- **心**：3 顆；答錯扣 1（跑跑：跑進錯的門／小魚：被大魚咬到）；心沒了＝結算。
- **第 2 圈**：8 區走完畫面重來、題目全部混著出、速度再快一點（真的很厲害的小孩才會到）。
- **打卡點**：存最遠到第幾區；第 3 區以後，介紹卡多一顆「從○○開始」（直接從上次最遠的前一區開始）。
- **星星**：每過一區 ⭐1 進星星罐，破紀錄多 ⭐1（一局最多大約 10 顆，跟其他遊戲一局 3 顆比起來時間也長很多，不會太好賺）。
- **統計／容易搞混**：答錯照主程式 noteMix 的規則記到家長頁。

## 2. 🏃 跑跑大冒險（mode `run`，js/zhuyin-run.js、css/zhuyin-run.css）

- 夥伴（目前選的寵物模型）在三條跑道上自己往前跑；左右滑或點畫面左右半邊換跑道（鍵盤←→也可以）。
- 每 6–8 秒前方出現一排「注音門」（拱門，各寫一個答案；第 1 區只有 2 個門，之後 3 個）。門出現時唸題目，題目同時顯示在上方（🔊 可重聽）。
- 跑進對的門：門炸成彩帶、＋連對、加速一點點；跑錯：門變灰、扣一顆心、夥伴跌一下、正確的門亮起來並唸一次正解。
- 門與門之間：金幣（一排排、可以收，結算算分）、偶爾一顆愛心、第 3 區起偶爾有木箱（撞到只會跌一下、少拿金幣，不扣心）。
- 區域：🏖️沙灘 → 🌲森林 → 🌷花田 → ❄️雪山 → 🍭糖果城 → 🌋火山 → 🌙夜空 → 🌈彩虹橋；一區 8 個門。
- 速度：第 1 區很慢（門從出現到抵達約 4.5 秒，讓 5 歲小孩讀得完），每區快一些，上限約 2.2 秒。

## 3. 🐟 小魚長大記（mode `grow`，js/zhuyin-grow.js、css/zhuyin-grow.css）

- 小孩的魚跟著手指游；不碰就慢慢漂。
- 上方任務牌：「吃 3 隻 ㄇ」（唸一次，🔊 可重聽），三個小圓點表示吃了幾隻。
- 海裡的小魚各帶一個注音泡泡（約 4 成是答案）；吃到對的＝長大一點＋任務點亮；吃錯的＝「噗」吐出來（不扣心，只是不算；連錯 2 隻，對的魚會發亮提示）。
- 大魚（比你大的）從邊邊游進來，進來前邊邊先出現「！」；被咬到扣一顆心、閃爍 2 秒無敵。
- 長大 3 段：每長一段，原本比你大的某些魚就變成可以吃（大口吃掉＋金幣，很爽的「反擊」時刻）。
- 一區 3 個任務；長滿＝進化成下一種海洋動物、游到更深的海：
  🐟小魚(淺灘) → 🐠熱帶魚(珊瑚礁) → 🐡河豚(海草森林) → 🐢海龜(沉船) → 🐬海豚(發光深海) → 🦈鯊魚(冰海) → 🐋鯨魚(火山海溝) → 👑魚王(寶藏宮殿)
- 魚用畫布自己畫（身體、尾巴、眼睛、鰭會擺動），不用表情符號。

## 4. 放在哪裡、多少貼紙開

- 主島 16 格全滿 → 兩款都蓋在**歸仁區**（30 張貼紙開，跟陀螺一樣）：仿東邊陀螺小半島，西邊加一塊（WEX，跑跑運動場，橫路往西接過去）、北邊加一塊（NEX，海洋館，直路往北接過去）。js/zhuyin-hub3d.js 的 WEX／NEX／STAD／AQUA、buildStadium、buildAquarium。
- ⚠️ 給音樂島（v8 第二批）：規格寫的島在 (−17,−21)、直橋備案 (−9,−20)；西邊小半島佔 x −7.6～0、z −21.9～−15.9（含沙灘再外擴 0.7），蓋橋時要避開或直接接到它。
- 介紹卡：沒玩過寫「🗺️ 8 區一路玩到底・越後面越難」；玩過寫最高紀錄＋打卡點切換鈕（見 §7）。
- 模式名 run／grow；存檔 zy{n}_endless（備份碼短鍵 en）。

## 5. 測試

- tools/zy-test/run-game.js、grow-game.js：開局、答對答錯、扣心、過區、結算、存檔、離開回小島；用網址參數加速（`?endless=fast`）跑完 2 區。
- 兩支「長時間」測試：模擬小孩 8 成答對一路玩，確認 10 分鐘左右還在玩（用加速時鐘算，不真的等 10 分鐘）。

## 6. 模組介面（實作用；兩款一樣）

檔案：跑跑＝js/zhuyin-run.js＋css/zhuyin-run.css（要 three，跟配送站一樣走 importmap）；小魚＝js/zhuyin-grow.js＋css/zhuyin-grow.css（2D 畫布，不要 three）。
出題一律用 js/zhuyin-endless-core.js 的 `createAsker`（不要自己出題）。

```js
export const LINES = { intro: "...", ... };       // 模組會用 api.talk 念的所有固定台詞（tools/voice/build_lines.py 會收；不要在別處寫死台詞字串）
export const ZONES = [{ name: "沙灘", ico: "🏖️" }, ...];   // 8 區（介紹卡、結算、打卡點用）
export function createRunGame(root, api)  /  createGrowGame(root, api)  →  { start(opts), stop(), relayout() }
```

`root`＝主程式給的 `<div id="runRoot">`／`<div id="growRoot">`（滿版、在 `<section class="screen">` 裡）。模組自己在裡面建所有畫面。
**左上角 110×110px 留給主程式的 🏠 鈕**（按了＝主程式的暫停／離開確認框）；右上角可以放模組自己的 🔊 重聽。

api（主程式提供）：
| 名稱 | 說明 |
|---|---|
| `say(text, alt, onEnd)` | 念題目：text＝預錄鑰匙（注音符號或國字），alt＝還沒錄音時給系統語音念的字；onEnd 可能不會來（要自己有保險計時） |
| `talk(text, onEnd)` | 貓頭鷹說明／鼓勵（家長可關掉「說明語音」，關掉時不念、onEnd 立刻來） |
| `play(name)` | 音效：ok ng coin pop splash star whoosh win ding select tap unlock ev_sparkle tp_ko tp_clash1 tp_clash2 tp_clash3 tp_launch tp_round tp_victory tp_count ev_burst |
| `later(fn, ms)` | 本局計時器（暫停選單開著會凍結、離開會清掉）；**所有 setTimeout 都用這個** |
| `paused()` | 暫停選單開著＝true：模擬要停（畫面可以照畫） |
| `stopVoice()` | 停掉正在念的那句（換題、重聽前用） |
| `speed` | 測試加速倍率（正式＝1；測試會給 3–6）：遊戲時間全部乘它 |
| `petGlb()` | （跑跑）夥伴模型網址，沒有＝null → 用 `IMAGE/zy3d/models/cat.glb` |
| `best()` | `{ zone, score }` 最佳紀錄（沒有＝{zone:0,score:0}） |
| `onAnswer({ ok, q, got })` | 每一題結果（主程式記統計、容易搞混、貼紙） |
| `onZone({ zone })` | 剛進入第 zone 區（0 起算；主程式存打卡點） |
| `onEnd(r)` | 心用完、演出完：`r = { zone, zonesCleared, score, coins, right, wrong, ms, words: [國字…], record }`（record＝破紀錄） |

`start({ zone = 0, intro = false })`：zone＝從第幾區開始（打卡點）；intro＝第一次玩（要手指示範操作）。
`stop()`：主程式離開時呼叫——停掉動畫、事件、語音、3D 資源全部釋放，之後不能再呼叫任何 api 回呼。
`relayout()`：畫面大小變了（轉向）。
測試掛鉤：`window.__zyRun`／`window.__zyGrow`＝{ state(), answer(ok), setZone(z), hurt() … }（只給測試用）。


## 7. 櫻木審查後定案（11-01，主對話拍板）

櫻木試算：原本「3 顆心、答錯扣 1、每區補 1」，答對 8 成的 5 歲小孩只有約 5% 走到第 8 區，多數 3–4 分鐘就結束 → 改成：
- **第 1 圈（第 1–8 區）＝旅程模式，不會輸**：跑錯／被咬＝掉金幣、跌一下、自動退級；8 區走完有大結局（r.finished），正常約 10 分鐘。
- **第 2 圈（區 ≥ 8）＝挑戰模式**：才有 3 顆心、心用完結束。要小孩在介紹卡自己選「🔥 挑戰第 2 圈」才開始（不自動接）。
- **休息一下**：第 2 區起過區畫面有「休息一下」鈕＝中途收工（r.rest），照樣結算拿星星；下次從那區接著玩。每進一區就存打卡點（at），🏠 中途離開也不丟。
- 介紹卡切換鈕：第 1 圈中途＝「🚩 從○○繼續」（預設開）；第 1 圈跑完＝「🔥 挑戰第 2 圈」（預設關＝重新走旅程）。
- 星星：每過一區 1 顆、破紀錄 +1（一局最多 10）；過區當下就飛進畫面角落的小罐子。
- 跑跑讀題時間依題目級數：1 級 4.5 秒、2 級 5、3 級 5.5、4–5 級 6.5、6 級 8.5（退過級再 +1）；只有第 2 圈 1–3 級可到 2.2 秒。答對的加速只是特效。門出現時下方有對齊跑道的答案卡（點卡＝換跑道）。每區第 4 個門後 8–10 秒金幣隧道。
- 小魚防亂吃：吃錯暈 1.2 秒、每個任務只回報第一次吃錯、12 秒沒吃對才提示、一口就吃對有金色獎勵、答案魚約 3 成（至少 2 隻）、第 4–6 級的魚游慢、字永遠正立。大魚進場有聲音＋紅光、前 3 區走直線最多 1 隻、只有嘴巴算咬到、無敵 3 秒。
- 第 3 級先不出 ㄝ ㄟ ㄥ（沒有好念的同音字給系統語音），等 Gemini 補錄。
- 收尾不出現「遊戲結束」：夥伴坐下喝果汁／小魚游回家＋8 區小地圖畫腳印，用門數講差多少。
- 上線後請阿葉帶小孩實測（櫻木清單）：跑跑前 3 局在第幾分鐘、因為什麼結束；跑錯門時問「你本來要跑哪一個」；小魚前 2 分鐘吃錯／吃對次數；結算 5 秒內會不會自己按繼續；iPad 上聽第 3 級韻母念得對不對。
