## 0. 全局規則（每個工作者都要遵守）

- 玩家：5 歲、已會拼讀注音、iPad 手指點。拋光標準＝Khan Academy Kids／Duolingo ABC／Toca Boca 等級。
- 阿葉拍板的規格不能動（見記憶 project-zhuyin-game.md「阿葉拍板過的規格」）：
  - **遊戲不自動唸答案**：看注音的題目完全不出聲；聽音題只開題唸一次；🔊／💡 按了才幫忙。
  - **每個國字旁都有注音**（自動旁注音 js/zhuyin-ann.js；新模組的中文字串要讓 tools/build_zhuyin_ui.py 掃得到——把新 .js 檔名加進它的 SOURCES，跑 `PYTHONIOENCODING=utf-8 python tools/build_zhuyin_ui.py`，`?debug` 下 `__zy.zMissing` 要是空的）。
  - 聲調跟注音同色；一聲不標。
  - 美術＝真 3D 等角小鎮風（Kenney＋自製 Blender 模型，跟小島同一套）。
- 遊戲內所有計時一律走 `api.later`（＝gLater），暫停選單才凍得住。
- 配音：新台詞先用瀏覽器語音頂著（say() 沒預錄會自動退回），**每個人把新台詞登記進 tools/voice/build_lines.py 自己的區塊**（用 `add(id, 文字, 類別, 來源)`＋`must()` 斷言），最後由主對話統一跑 gen_batch.py 錄音。台詞要短、口語、台灣用語，給 5 歲小孩聽。
- **不要升 ?v= 版號、不要 commit**——主對話最後統一做（多人同時改，版號會打架）。
- 多人同時改同一檔：只准用 Edit 精準替換，不准整檔覆寫；Edit 失敗（檔案被別人改了）就重讀再改。
- 測試：專案根目錄 `python -m http.server 8765`（可能已有人開著，先 curl 看看），headless 測試在 tools/zy-test/，共用 lib.js。

## 2. 彩虹配送站（新遊戲，mode="deliver"）

### 2-1 核心循環（一個任務）
1. 開場：3D 小地圖（倉庫在左、幾戶人家、道路、可能有河與吊橋），卡車停在倉庫。訂單卡從上方滑入（叮咚聲），每張＝居民頭像＋商品（圖或「？」）＋國字（自動注音）。前 3 關居民會開口說一次「我要帽子！」。
2. **裝貨**（卡車在倉庫時，下方出現貨架）：點商品 → 商品跳起來發光 → 點卡車（3D 卡車或右下車廂面板任一處）→ 商品飛進車廂、3D 卡車的平台上出現那個商品的小模型。車廂格數＝容量。在倉庫點車廂裡的貨＝放回貨架。車廂滿了再裝：格子抖一下＋「車子裝滿了！」。
3. **開車**：點地圖上的目的地圖釘（某戶人家或倉庫）→ 卡車沿合法最短路自動開過去（發動聲、行駛聲、轉彎、到站煞車＋叭叭）。開車中不吃其他點擊（暫停除外）。走不到（橋升起、單行道）→ 卡車不動，擋路的東西閃爍＋說明（「橋還沒放下來喔！」）。空車要出發 → 「先把貨裝上車吧！」並讓提示鈕亮。
4. **送貨**：到了有訂單的人家，居民走出來；點車廂裡的一件貨 → 飛給居民。
   - 對：居民開心跳＋「謝謝你！」＋金幣/星星飛到訂單卡、卡片蓋 ✓。
   - 錯：居民搖頭，貨飛回車上（＝取回重選），並**說出具體的錯**：「這是蘋果，不是我要的喔！」（說的是孩子給的那個，不唸答案），訂單卡閃一下。
   - 車上沒有他要的 → 「車上沒有我要的東西耶，回倉庫拿吧！」倉庫圖釘亮。
   - 到了沒訂東西/已經收到的人家 → 「我已經收到囉，謝謝！」或「我沒有訂東西喔！」
5. 全部送完 → 任務完成（卡車按喇叭、居民一起揮手）→ 結算星星 → 第一次過關居民送一件**換裝禮物**（見 §3），飛進衣櫃。

### 2-2 注音怎麼融入（不准「答對一題車才走一步」）
- 貨架商品：永遠是 3D 渲染圖＋國字（自動注音）。
- 訂單：任務 1–3＝圖＋國字注音＋居民唸一次；任務 4 起＝**藏圖**（「？」紙箱）只剩國字注音、居民只打招呼不唸商品。💡 第一次按＝揭開那張訂單的圖；再按＝示範下一步。
- 6 種商品刻意有易混組：麵包／帽子（都是ㄇ開頭）、西瓜／香蕉（都是ㄒ開頭），逼孩子讀到第二個音。

### 2-3 提示鈕 💡（示範，不是再念一遍）
- 用求解器算「從現在狀態走最佳解的下一步」，然後**動畫手指**示範：指商品→指卡車／指目的地圖釘／指要交出的貨／指橋的開關。手指會做按壓動作＋光圈。
- 錯 2 次或閒置 N 秒（家長設定 zy_hint_wait）只讓 💡 閃，不自動示範。

### 2-4 大人也想玩的部分（規劃，不限時）
- 車廂容量、單行道、吊橋開關（開關在倉庫，只能在倉庫切換）、送貨順序。
- 星星：送錯次數＋「出車趟數/總路程」跟求解器最佳解比。3★＝沒送錯且趟數＝最少、路程 ≤ 最佳×1.05；2★＝最多多一次錯或多一趟；其餘 1★。結算時小字顯示「最少 N 趟／你用了 M 趟」（大人看的）。

## 5. 音樂音效升級

- 現況問題（2026-10-11 實測）：主選單 BGM 只有 44 秒單聲道 64k、峰值 +3.4 dBTP 會破音；HTMLAudio loop 有接縫；iPad 上 HTMLAudio.volume 無效所以「講話壓低音樂」可能沒作用；切曲沒淡入淡出；切到背景 BGM 不停；音效被 currentTime=0 切斷；沒有主音量。
- 工具選擇（研究見 scratchpad research-audio.md）：音樂主力＝**Gemini API Lyria**（lyria-3.5 一首 0.08 美元、可程式化批次、指定 Instrumental only），每個場景生 2–3 首候選，用 Gemini 聽音檔評分＋響度檢查挑最好的；Suno 帳號若是付費方案，主題曲另用 Suno v6 生候選比較。音效＝**Kenney CC0 音效包**（Interface/Impact/UI Audio/Digital Audio/RPG Audio/Music Jingles）＋**Freesound CC0**（卡車、喇叭、海鷗、水花等），授權乾淨免署名。
- 曲目（key → 用途）：`island`（主島選單＋多數遊戲，明亮輕快）、`calm`（積木/翻牌/青蛙，溫和思考）、`town`（在歸仁區時的選單）、`rainbow`（在彩虹島時的選單）、`night`（晚上的選單，搖籃曲感）、`road`（配送）、`dress`（換裝）、`bubble`（泡泡）、結算 jingle `party`。
- 無縫循環做法：挑小節邊界當循環段，檔案＝〔循環段最後 0.5 秒〕＋循環段（尾端烘焙交叉淡化）＋〔循環段最前 0.5 秒〕，程式用 Web Audio `loopStart=0.5、loopEnd=0.5+L`——這樣 mp3 解碼器的固定延遲不影響接縫。
- 響度：BGM 檔案正規化到約 -18 LUFS、true peak ≤ -1.5 dBTP；音效峰值 ≤ -3 dBFS、彼此聽感一致；配音維持現狀（約 -18）。實際音量比例在程式的 bus 增益調。
- 引擎（zhuyin.js 音訊段＋zhuyin-voice.js＋weather 聲音）：一個 AudioContext、master gain → limiter → 輸出；四條 bus：music／sfx／voice／ambience。BGM 用 AudioBufferSource 無縫循環、切曲 0.6 秒交叉淡化、配音時 music bus 用 ramp 壓低（約 -10 dB，150 ms 進、400 ms 出）、visibilitychange 時暫停/恢復；音效預先 decode、可重疊播放；音樂開關管 music＋ambience。延遲載入：先載選單要用的，其他背景載。
- 給阿葉的試聽頁 `tools/audio/audition.html`：每個場景的候選並排，標出目前選用的那首；阿葉想換只要跟 Claude 說。
