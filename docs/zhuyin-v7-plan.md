## 1. 注音戰鬥陀螺 v2：合體＋三戰兩勝（分身 T）

參考 lpm1.live 戰鬥畫面（截圖在 D:\Claude\Projects\GAME DIY\.playwright-mcp\lpm1-1~4.png）：字本身是立體陀螺在碗形場地互撞，**撞擊時碎成小方塊飛出去**、兩邊各有「完整度 %」、上方三個圓點＝三戰兩勝進度、黑隊對紅隊兩種顏色、每回合結束大字「本回合 X 勝」。

1.1 **合體轉場**（5 個字確定後）：五顆小陀螺各帶一個字飛到中間、繞圈越轉越快 → 白光一閃＋震動 → 變成一顆大陀螺（頂面一圈印著五個字）。貓頭鷹／字幕「合體！」。約 3 秒，第二次起可點一下跳過。
1.2 **一顆對一顆**：合體陀螺的能力＝五個字能力的合成（重量、穩定、攻擊、防禦；做法自己定，要寫清楚）；**戰力數字不變**（排行榜用的是 js/zhuyin-tops-power.js，後端 TopsPower.gs 是同一份公式的副本 → 公式不准改，不然要重新部署後端）。
1.3 **三戰兩勝**：每回合：「3、2、1，發射！」→ 兩顆陀螺互撞 → 一方轉不動（耐力歸零）或被撞出場＝這回合輸。先拿 2 勝贏。對戰仍是**確定性模擬**（同樣兩句話、同一回合結果一樣，不耗算力），但三回合要有變化（每回合用不同種子），戰力高的贏面大但不是必勝。
1.4 **刺激感**（照 lpm1 與競技動畫）：
- 兩顆陀螺**顏色不同**：小孩＝藍青隊、對手＝紅橘隊；名字牌、血條、得分點都用隊伍色。
- 撞擊：火花、碎片（陀螺外殼碎成小塊飛出去，像 lpm1 的方塊）、衝擊圈、畫面震動、撞擊瞬間短暫停格；重擊時鏡頭拉近。
- 上方：兩條「耐力／完整度」長條、三個得分圓點、ROUND 1/2/3。
- 決勝一擊慢動作；回合結束大字「藍隊勝！」；整場結束「勝利！」或「再接再厲」。
- 音效與音樂：見 §3（音檔由主對話與分身 S 提供，鍵名固定）。
1.5 **難度＝對手段位**：新手 → 銅 → 銀 → 金 → 彩虹。贏一場升段（存檔），越高段對手戰力越接近或略高於小孩的；第一次一定遇到打得贏的對手（原規則保留）；輸了安慰、可免費換對手（原規則保留）。介紹卡顯示目前段位。
1.6 保留：陀螺券（15 星換 1 張）、排行榜送出、字典、灰鍵、骰子填空。

## 2. 寵物進化（分身 P）

現況：js/zhuyin-rewards.js 有 28 隻寵物、夥伴（partner）、點心餵食「長大」（30／110 點心兩階段）；3D 模型 IMAGE/zy3d/models、2D 圖 IMAGE/zhuyin/pets/*.webp；換裝配件（皇冠、翅膀、披風…）是 3D 模型掛在寵物 anchors 上。

2.1 **第三階段「進化」**：長大到最後一階的夥伴，**進化能量**集滿 100 就進化。能量來源：當夥伴時玩遊戲第 3 級以上拿 3 星 +10、爬塔第一次到新樓層 +2、打倒守塔怪 +40、每天第一次餵點心 +5。（數值自己可微調，寫在程式常數。）
2.2 **進化後外型**：名字前加「超級」（超級小象）；3D：模型略大（約 1.15 倍）＋常駐光環／粒子＋一個進化徽記（小星冠或背光翼，可沿用換裝配件模型改色）＋配色更亮；2D 圖鑑／介紹用 CSS 疊光暈＋徽記（不一定要重畫 28 張）。小島上走動的那隻也要看得出是進化型。
2.3 **進化演出（數碼寶貝式，約 8–10 秒）**：畫面暗下、背景變成流動的數位格線／光帶 → 寵物浮起並**旋轉**（越轉越快）、身體變成發光剪影、周圍有旋轉的光環與數位碼雨 → 字幕＋配音「小象進化——」→ 白光爆開 → 新外型亮相擺姿勢、名字橫幅「超級小象！」、彩帶 → 音樂在亮相時到最高點。第一次完整播放，之後可點一下跳過。尊重「減少動態」設定。
2.4 **在哪裡觸發**：能量滿時回小島，貓頭鷹說「XX 好像要進化了！」，夥伴頭上出現發光圖示，點一下開始演出（不要在遊戲中途打斷）。圖鑑「動物朋友」分頁顯示進化能量條與進化剪影。
2.5 存檔：rewards 裡加 evo 能量與已進化名單，清洗＋備份碼要帶。家長頁可看。
