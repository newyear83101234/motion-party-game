# 注音小島 3D 大改版計畫（2026-10-10 阿葉拍板「走 C、直接大改」）

## 目標
把注音小島整體美術改成「真 3D 等角小鎮」風，參考 Tack Lin《開工吧！社畜人生！》（參考影格在 `IMAGE/_src/iso/ref/`，未進 git）。
**玩法不動**：八個遊戲的規則、語音規則、存檔、注音標示都維持現狀（tools/zy-test 的測試必須照樣全過）。

## 架構決策
| 部分 | 做法 |
|---|---|
| 選單 | Three.js 即時 3D 小島（`js/zhuyin-hub3d.js`），每棟建築＝一個遊戲，點建築進遊戲。WebGL 不行／載入逾時 → 退回原本的卡片選單 |
| 遊戲背景 | 用同一套 3D 模型「預先渲染」成 webp（渲染工作站 `tools/render3d/`，headless Chromium＋Three.js，光影跟選單一致） |
| 遊戲道具／角色圖 | 同上，預先渲染成透明背景 webp，沿用現有檔名（程式少改） |
| 自製模型 | Blender 5.2.2（`C:\Users\newye\tools\blender-5.2.2-windows-x64\blender.exe`）無頭 bpy 腳本 `tools/blender/*.py` → GLB 到 `IMAGE/zy3d/models/` |
| 現成模型 | Kenney CC0（解壓在 `IMAGE/_src/iso/kits/<套件>/`，用到的才複製進 `IMAGE/zy3d/kenney/<套件>/`） |
| 詞的圖 | 136 個詞仍用 emoji（跨遊戲辨識用，這輪不換） |

## 風格規範（從 Tack Lin 影格取）
- 相機：正交（orthographic）等角，水平 45°、俯角約 30–35°；畫面乾淨、低多邊形、平塗色＋柔和陰影
- 小島：草地頂面 → 一層咖啡色土壁（分層台地感）→ 沙灘 → 淺水青綠 → 深水藍，深水面有淡白格線
- 色票（近似值，實作可微調）：深水 `#3f97c9`、格線 `#5fa9d6`、淺水 `#7fcfd0`、沙 `#ecd7a3`、土壁 `#a8673f`／暗 `#7d4a2e`、草 `#86c449`／暗 `#5f9c3a`、廣場石板 `#ddd8cf`、道路 `#bdb8b1`、紫色建築 `#8b70cc`／深紫 `#5e4aa8`、奶油牆 `#f0e7d3`、深綠屋簷 `#2f6b50`、粉紅條紋棚 `#f2808f`、秋橘樹 `#f08a3c`、木平台 `#c98a55`
- UI：白色圓角膠囊＋深青文字 `#24515c`、重點黃膠囊 `#f6c445`＋深藍字；保留目前的注音標示系統
- 角色：Kenney Cube Pets 方塊動物風（大眼、方身），自製角色比照這個比例

## 交付清單
1. **D1 3D 選單小島**：8 棟建築對應 8 個遊戲（釣魚＝碼頭、點餐＝餐車/小店、積木＝積木屋、尋寶＝公園、翻牌＝卡牌屋、氣球＝氣球攤、地鼠＝菜園、青蛙＝池塘）；未解鎖＝施工圍籬＋鎖頭牌；建築上方浮標（圖示＋兩字國字，自動加注音）；已孵出的朋友（方塊動物）在島上走動、點了會跳；輕微自動漂移鏡頭；遊戲中停止渲染（省電）
2. **D2 自製模型**（Blender）：地鼠（一般／被敲暈）、青蛙、貓頭鷹嚮導（學士帽）、棕熊（Cube Pets 北極熊改色）、氣球（4 色）、蛋（斑點＋裂痕版）、地鼠洞
3. **D3 遊戲背景**：fish/order/build/hunt/match/tone/whack/frog＋選單備援/結算/圖鑑，橫式＋直式各一張
4. **D4 道具／角色圖**：fish、balloon×4、mole_up_body/mole_hit_body/hole、frog_sit/frog_jump、lilypad/lilypad_flower、stone、card_back×2、egg、guide_owl、8 位客人
5. **D5 介面換色**：照上面 UI 規範調整按鈕／膠囊／進度條
6. 驗收：tools/zy-test 全過、橫直式＋4:3 截圖給寧次審、程式給里維審、iPad 效能（選單 60fps 目標、首屏載入 < 4 秒 @4Mbps）
