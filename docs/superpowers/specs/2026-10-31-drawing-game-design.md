## 1. 目標與對象

- 給 3～10 歲的小孩玩，介面以 6～10 歲的標準設計；全部用圖示，不需要認字
- 裝置：iPad 橫向。直向時整頁蓋上「請把平板轉橫」的圖示，不另外做直向版面
- 成功的樣子：
  1. 小孩不用大人教，能自己完成一張畫並按下完成
  2. 填色從不漏到別塊
  3. 在 iPad 上手指畫線不會有明顯延遲

## 2. 第一版做什麼、不做什麼

**做**：選圖、填色、筆刷、材質、貼紙、橡皮擦、復原、清空、兩指縮放、完成動畫、作品牆、8 張線稿。

**不做**（之後再說，見第 11 節）：
- 拍照變線稿（要接 AI）
- 任何聲音：阿葉選「只要動，不要聲音」，為了一致，第一版全程不出聲
- 加進總選單：第一版跟方塊爆破一樣，直接用 `draw.html` 網址開

## 3. 畫面流程

1. **首頁**：上排 4 個主題圖示（動物、交通工具、恐龍、公主），點下去出現該主題的線稿縮圖。縮圖角落用 1 顆星標「簡單」、3 顆星標「困難」。右上角是作品牆入口。
2. **畫畫頁**：左邊是畫布（盡量放大），右邊是一條直的工具列（排法見第 4 節）。
3. **完成**：按 ✓ 後先播完成動畫（第 6 節），再自動存進作品牆。畫面上出現兩個圖示：「回首頁」和「繼續畫這張」。

## 4. 工具

工具列由上到下：
- 完成 ✓、回首頁
- 四種工具（同一時間只能選一種）：填色桶、筆刷、貼紙、橡皮擦
- 顏色、材質、不出線開關
- 復原、清空

按回首頁時，還沒畫完的畫會自動存進作品牆並標成「未完成」，這時不播完成動畫，之後可以接著畫。

| 工具 | 行為 |
|---|---|
| 填色桶 | 點哪一塊就把那一塊填成目前的顏色和材質；顏色從手指點的位置像水波一樣擴散開，約 0.4 秒填滿 |
| 筆刷 | 選了筆刷之後再點一次，會跳出筆的種類和粗細：馬克筆（實心）、蠟筆（有顆粒紋理）、彩虹筆（邊畫邊漸變顏色）；粗細分小、中、大三段 |
| 不出線開關 | 預設打開：筆畫只會留在起筆的那一塊裡，背景也算一塊。關掉之後可以跨塊自由畫 |
| 顏色 | 跳出 24 色的顏色盤，選完自動收起 |
| 材質 | 純色、亮粉，以及 5 種圖樣（星星、愛心、點點、條紋、雪花）。材質只套用在填色桶和馬克筆上；蠟筆和彩虹筆有自己固定的樣子 |
| 貼紙 | 選了貼紙之後再點一次，會跳出 12 種原創貼紙（自己畫的向量圖）；選好之後，在畫布上點一下就蓋上去，大小跟著筆刷粗細走 |
| 橡皮擦 | 把顏色、筆畫、貼紙擦回白色；黑線擦不掉 |
| 復原 | 最多可以退 30 步 |
| 清空 | 要按住 1 秒才會清空，按鈕上有一圈進度條，避免小孩不小心按到 |
| 縮放 | 所有線稿都可以兩指放大、移動；兩指點兩下回到原本大小 |

**防手掌誤觸**：畫畫只認第一根手指。150 毫秒內第二根手指也碰到螢幕，就取消剛開始的那一筆，改成縮放。

## 5. 填色怎麼做（技術核心）

- **線稿格式**：PNG，白底黑線，長邊 2048 像素。線條必須是封閉的。
- **開圖時自動切塊**：把深色像素當成線，其餘白色的部分找出彼此相連的區域，每一塊給一個編號（區塊編號表，用 `Int32Array` 存）。任何黑線線稿都能這樣切，所以以後拍照轉出來的線稿可以直接接上。
- **兩層畫布**：
  - 下層是「顏色層」：填色、筆畫、貼紙都畫在這裡
  - 上層是「線稿層」：只有黑線，白色部分變成透明
  - 黑線永遠疊在最上面，所以填色的邊緣看起來一定乾淨
- **不留白縫**：填色時，把該塊的範圍往外多塗 2 像素，塞到黑線底下。
- **亮粉閃爍**：記錄哪些區塊和筆畫用了亮粉，閃光另外畫在一層動畫層上，不改到顏色層。
- **復原**：每一步只存「被改到的那個長方形範圍」改動前的影像，用來省 iPad 記憶體。
- **純邏輯分開寫**：切塊、填色範圍、復原紀錄寫在 `draw-core.js`，這個檔不碰畫面，可以在 node 裡直接測。

## 6. 完成動畫（沒有聲音）

1. 把兩層畫布合成一張
2. 整張圖「蹲低、跳起、落地再彈一下」，約 1.2 秒
3. 零件動作：每張線稿在設定檔裡指定，例如眨眼、輪子轉、尾巴搖、裙子擺。做法是用座標點指出是哪幾塊，程式切出那幾塊，再繞著設定好的支點旋轉或縮放
4. 最後撒一陣彩帶

以後拍照轉出來的線稿沒有零件設定，就只做跳一下加彩帶。

## 7. 線稿（第一版 8 張）

| 主題 | 簡單（大塊，約 8～15 塊） | 困難（細節多、有背景，約 30～60 塊） |
|---|---|---|
| 動物 | 小貓（眨眼、尾巴搖） | 大象和小鳥（眨眼、鼻子擺） |
| 交通工具 | 小汽車（輪子轉） | 蒸汽火車（輪子轉、煙飄） |
| 恐龍／怪獸 | 小暴龍（眨眼、尾巴搖） | 長頸龍和火山（頭擺、火山冒煙） |
| 公主／童話 | 獨角獸（眨眼、尾巴搖） | 城堡和公主（裙子擺、旗子飄） |

圖案名稱是暫定的，生圖時看效果可以換。

- **生成方式**：用 ChatGPT 網頁版生圖（沿用專案既有的生圖流程），提示詞要求粗黑線、線條封閉、沒有灰階和陰影、原創角色。
- **檢查工具**：`tools/draw-test/lineart-check`。它會數出幾塊、找出太小的碎塊，並輸出一張「每塊隨機上不同顏色」的預覽圖。我用眼睛看預覽圖找漏縫：兩塊顏色連成一片，就代表中間的線沒封好。
- **設定檔**：每張線稿配一個 JSON，記錄名稱、主題、難度和零件動作。

## 8. 作品牆

- **存哪裡**：存在 iPad 瀏覽器的 IndexedDB（瀏覽器內建的資料庫），每件作品存三樣：縮圖、完整作品圖、可以接著畫的狀態（顏色層加上是哪張線稿）。
- **能做什麼**：點開放大看、接著畫、存到相簿。存相簿是用分享功能（Web Share API）把圖片交給 iPad 的分享選單，再按「儲存影像」；不支援分享的瀏覽器改成直接下載。
- **上限**：最多保留 50 件，未完成的也算在內。滿了之後，存新作品前會跳出「作品牆滿了」的圖示，由大人自己挑舊的刪掉，程式不會自動刪。
- **資料遺失風險**：
  - 清除 Safari 的網站資料，作品會一起不見
  - Safari 會刪掉 7 天沒開的網站資料，加到主畫面的網頁不受影響（這是 2020 年 WebKit 公布的規則，實作前要再查證現在是否還一樣）
  - 對策：開頁時向瀏覽器申請「不要自動清除」（`navigator.storage.persist()`），並在作品牆角落放一個「加到主畫面」的圖示教學

## 9. 檔案結構（照方塊爆破的做法）

```

css/draw.css
js/draw-core.js           切塊、填色範圍、復原（純邏輯）
js/draw-canvas.js         四層畫布、縮放平移、座標換算
js/draw-paint.js          材質、筆刷、橡皮擦、貼紙蓋章、復原紀錄
js/draw-stickers.js       12 種貼紙（向量圖字串）
js/draw-fx.js             填色水波、亮粉閃爍、完成動畫
js/draw-gallery.js        作品牆存取
js/draw.js                畫面和流程
IMAGE/draw/lineart/       線稿 PNG、縮圖 thumbs/、設定檔 index.json
tools/draw-test/          自動化測試、線稿檢查、效能量測
```

（實作時把原訂的 `draw-tools.js` 拆成 canvas／paint／stickers 三個檔；貼紙改成程式內建的向量圖，不另外放圖檔。）

commit 一律只加具體檔名。GAME DIY 工作資料夾裡有 212 個檔案在 10-30 被搬去 `party game`，用 `git add -A` 會把那些檔案（包括部署設定）一起刪掉。

## 10. 測試與驗收

1. **node 單元測試**（`draw-core.js`）：用已知的小圖驗證切出的塊數、填色不漏到別塊、復原後跟原本一模一樣。
2. **瀏覽器自動化測試**（Playwright，模擬 iPad 1180×820 觸控）：選圖、填色、不出線筆刷、復原、清空長按、完成動畫、作品牆存檔和讀回。
3. **線稿檢查**：8 張都要跑檢查工具，再用眼睛看上色預覽圖。
4. **效能目標**：在 iPad 上，開圖切塊不超過 0.5 秒；點下填色到開始出現動畫不超過 0.1 秒。
5. **程式審查**：前端程式找里維，畫面好不好用找寧次。
6. **實機試玩**：最後由阿葉用 iPad 實際玩過才算完成。
