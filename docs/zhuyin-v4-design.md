# 注音小島 v4 設計（櫻木花道 2026-10-10，主對話存檔）

對象：5 歲、已會拼讀注音、平板手指點。依據當天的 js/zhuyin.js、js/zhuyin-words.js、css/zhuyin.css。

## 0. 總判決
小孩不是膩了遊戲，是膩了「玩了沒東西拿」。v3 的獎勵第 3-7 天就全部發完（一天約 6 局、14 星：4 顆蛋第 3 天孵完、解鎖門檻第 1 天就過、136 張貼紙約第 5-7 天貼完）。v4 要把獎勵從「一次性解鎖」改成「越養越大的夥伴」，再補兩個「會動」的新關卡。

保留：無命制、錯了只變暗、金星銀星、提示只在小孩要的時候給、答對後再點一下直接下一題、優先出新詞。

地雷：
1. [高] Safari 7 天規則會清 localStorage → 備份碼（已做）＋加到主畫面
2. [高] 獎勵一次性 → C 整套重做
3. [高] 隨機稀有＋集滿一套換獎＝日本 2012 年禁止的 kompu gacha → 全部改學習里程碑、不隨機、事先公開
4. [中] 連續天數斷了歸零 → 改集章卡
5. [中] 「明天再來」、角色說會想你＝Radesky 2022 列為操弄設計 → 不做
6. [中] 儀式疊太多 → 每次結算最多 2 個、≤20 秒
7. [中] 打地鼠速度跟不上 5 歲讀注音 → 探頭時間自動調整
8. [低] 跳跳蛙掉水比跳對好笑 → 跳對特效要更大

## A. 兩個新關卡

### A0 共通
聽音題開題只唸一次；之後只有按「再聽」才唸；錯 2 次提示鈕閃；已錯 ≥2 次再按提示正解輕晃；閒置秒數照家長設定，只閃不出聲；新詞拿金星貼貼紙。

### A1 注音打地鼠（練一眼認出整個音節的速度）
核心：目標卡只放圖、開題唸一次 → 3×3 洞地鼠舉注音牌冒出 → 敲中正解亮一顆圓點 → 3 顆亮了目標卡翻面露國字＋注音、唸一次、換下一個目標。

| 項目 | 數值 |
|---|---|
| 解鎖 | 貼紙 20 張 |
| 一局 | 6 個目標：前 3 單音節、後 3 雙音節 |
| 每個目標 | 敲中 3 次 |
| 同時探頭 | 目標 1-3 最多 2 隻；4-6 最多 3 隻；同時最多 1 隻舉正解 |
| 冒出間隔 | 1-3：1.0-1.4 秒；4-6：0.8-1.2 秒；同一洞兩次之間 ≥0.6 秒 |
| 探頭時間 | 起始 單 3.5 秒／雙 3.8 秒；連續 2 次剩 ≥1.5 秒敲中→-0.2 秒；正解連續 2 次沒被敲縮回→+0.4 秒；下限 2.2/2.8、上限 4.5/5.0；跨局記住 |
| 正解出現率 | 45%；超過 2.5 秒沒正解，下一隻一定是 |
| 干擾牌 | 目標 1-2 聲韻都不同；3-4 同聲母或同韻母；5-6 多一張改聲調的假牌 |
| 動畫 | 冒出 0.25、縮回 0.25、被敲 0.45 秒 |
| 敲錯 | 輕咚、地鼠搖牌縮回；0.5 秒點擊無效；錯數 +1 |
| 正解縮回 | 不算錯 |
| 提示 | 再聽隨時能按（暫停冒出 1.5 秒）；錯 ≥2 次再按 → 下一隻正解牌鑲金邊、場上正解晃 |
| 金星 | 每目標錯 ≤1 |
| 星數 | 金星 ≥5→3 星、≥3→2 星、其他 1 星 |
| 一局 | 約 80-110 秒 |
| 連擊 | 連 5 次沒錯→金色地鼠（純視覺） |

技術：pointerdown 觸發；計時 requestAnimationFrame、背景暫停；多點觸控照收。
版面：橫式左 28% 目標卡、右 3×3；直式上 22% 目標卡、下 3×3；牌上注音單 5vmin、雙 4.2vmin。

### A2 注音跳跳蛙（聽整個詞→切音節→依序找注音）
核心：石頭上放詞的圖、唸一次 → 面前 2-3 片荷葉各一個音節 → 點對青蛙跳上去荷葉開花 → 跳完最後一個音節落到石頭、音節組成整個詞＋國字、唸一次 → 5 個詞跳完到對岸。

| 項目 | 數值 |
|---|---|
| 解鎖 | 貼紙 25 張 |
| 一局 | 5 個詞：2、2、2、2、3 音節，共 11 跳 |
| 進階 | 玩過 3 次且拿過 3 星 → 第 5 個詞換短語 |
| 荷葉 | 第 1 個詞 2 片，之後 3 片 |
| 干擾音節 | 詞 1-2 聲母不同；3-4 同聲母或同韻母；5 加一片同音不同聲調；排除本詞任何音節 |
| 時限 | 沒有 |
| 跳躍 | 0.45 秒弧線；下一排滑入 0.35 秒；鎖輸入約 0.8 秒 |
| 跳對 | 荷葉開花，叮聲每連對高半音（最多 8 階） |
| 跳錯 | 荷葉翻、小水花、0.9 秒回原位；那片沉掉；錯數 +1 |
| 提示 | 再聽只唸整個詞；錯 ≥2 次再按 → 正確荷葉晃 1.5 秒 |
| 金星 | 2 音節 0 錯；3 音節或短語 ≤1 錯 |
| 星數 | 金星 ≥4→3 星、≥3→2 星、其他 1 星 |
| 一局 | 約 70-100 秒 |

防故意跳水：掉水動畫小而短、沒好笑音效；跳對特效大 3 倍。
版面：橫式 青蛙 x=18%、荷葉 x=50% 直排、石頭 x=82%；直式 青蛙 y=80%、荷葉 y=50% 橫排、石頭 y=18%；荷葉 20vmin、注音 6vmin。

備案：注音送信（拖曳）。不建議：注音描寫、語音辨識。

## B. 翻牌擴充

| 項目 | 8 張 | 16 張 | 24 張 |
|---|---|---|---|
| 橫式 | 4×2 | 4×4 | 6×4 |
| 直式 | 2×4 | 4×4 | 4×6 |
| 3 星（錯配 ≤） | 4 | 10 | 16 |
| 2 星（錯配 ≤） | 8 | 18 | 28 |
| 錯配停留 | 0.9 秒 | 1.2 秒可點掉 | 1.2 秒可點掉 |
| 5 歲估時 | 0.7-1.2 分 | 1.5-2.5 分 | 2.5-4 分 |

門檻依據：完美記憶最佳錯配約 0.61n−0.5（Velleman & Warrington），取 2-2.3 倍。
輔助：1) 兩色卡背（圖卡橘、注音卡藍；第二張點到同色只晃一下、不算錯）2) 翻過的卡留腳印（16/24）3) 錯配停 1.2 秒可點掉 4) 配對成功卡留原位變綠 5) 連錯 5/6 次提示鈕閃 6) 24 張配到第 6 對夥伴加油。
圖卡白名單：排除顏色、人物、動作、圖意會偏的（水、杯子、積木、玩具、湯、嘴巴）、三音節；同盤不放同類圖（雞＋小雞）、8/16 張不放共用音節（熊＋熊貓）。

## C. 獎勵系統提案（待阿葉確認才實作）

六條底線：完全不隨機（剪影事先公開）／稀有靠學習里程碑／永不倒退（不扣、寵物不餓不難過不離家、集章不歸零）／不催回來／沒有付費感／星星只來自完成關卡、點心只來自答對。

C1 核心循環：每題答對→點心飛給夥伴；每局 1-3 星→星星罐；罐滿→照固定順序開出蛋、家具、服裝或大點心盒。（「答對餵寵物，玩完裝星星，罐子滿了開禮物」）
C2 進化 3 段：寶寶→長大（40 點心）→超級（再 100）。既有 8 隻用現在的圖當「長大」，補超級型態。進化儀式只在結算：發光→點 5 下或 6 秒→白閃→新型態＋注音名字，5-8 秒。
C3 星星罐：前 2 罐 10 星、之後 15 星；玻璃裡看得到獎品剪影；首頁「再 X 顆星」；開罐：發光搖晃→點 3 下或 3 秒→蓋子彈開→獎品升起變彩色。固定序列：熊貓蛋→小床→企鵝蛋→帽子→青蛙蛋→大點心盒→小獅子蛋→盆栽→小象蛋→鞦韆→…（大點心盒＝+20 點心）。
C4 孵蛋 6 段：落巢→搖（點一下晃）→裂痕（點 3 下或 2.5 秒）→裂網透光（6 下或 5 秒）→破殼光爆（9 下或 7.5 秒）→登場唸名字，4-11 秒；裂痕用 SVG。
C5 稀有度（不隨機）：森林蛋＝星星罐（普通）；星光蛋＝貼滿一個分頁→小恐龍、全部貼滿→小鯨魚（稀有，紫藍光）；彩虹蛋＝閃亮貼紙 100 張→彩虹小龍（超稀有，彩虹光）。系列「動物朋友」12 隻。畫面不出現「稀有」兩字。
C6 貼紙一直有用：答對已貼的詞也出點心；閃亮＝之後 3 個不同天金星答對（間隔複習），出題 50% 新詞 40% 複習 10% 隨機；18 個套組徽章（每拿一個送一件小窩裝飾）；里程碑（閃亮 30→蝴蝶結、60→魔法帽、100→彩虹蛋、136→皇冠）；小窩貼紙牆。
C7 寵物小窩：寵物走動、點了跳一下＋叫聲＋注音名字，連點 3 下跳舞；換夥伴、換裝、擺家具和貼紙、信箱；顯示「你來島上 N 天了」。
C8 每日禮物與集章卡：每天第一局送一件裝飾、集章一格；7 格換服裝；不要求連續、不歸零。
C9 首頁：夥伴頭像＋「再 X 個長大」、罐子「再 X 顆星」、「動物朋友 10/12、貼紙 128/136、閃亮 45」。
C10 節奏：每題點心、每局星、每 2-3 局小解鎖、每天約 1 罐、每 2-3 天 1 次進化、每週集章卡、約每 1-2 週 1 隻稀有。一次結算最多 2 個大儀式（進化>孵蛋>開罐>徽章），≤20 秒，其餘進信箱；遊戲中途不出現大儀式。

C11 節奏表（阿葉小孩：已有 8 隻、約 100 張貼紙；一天 6 局、14 星、約 45 點心）
| 天 | 拿到什麼 |
|---|---|
| 第 1 天 | 選夥伴；補發已集滿的徽章、可能直接拿到小恐龍；第一罐開出小象蛋；集章 1/7 |
| 第 3 天 | 第一次進化；共開 3 罐；閃亮約 10 張 |
| 第 7 天 | 集章卡滿換披風；超級 2-3 隻；貼紙全滿孵出小鯨魚；系列 11/12；閃亮 50-60 張 |
| 第 30 天 | 12/12 全到（彩虹小龍約第 11-14 天）；全員超級（約第 26-30 天）；全閃亮換皇冠；18 徽章；約 28 罐 |
主線約第 25-35 天收完，之後需要每月內容包（8 新詞＋1 隻寵物）。

C12 美術：必要約 40 張（8 隻超級型態、4 隻新寵物×3 段、3 種蛋、罐子 2、小窩背景、打地鼠 5、跳跳蛙 8），選配約 28 張；建議美術風格定案後再生。

C14 要阿葉拍板：1) 連續天數改集章卡？ 2)「再答對 X 題就孵化」改放寵物成長、罐子顯示「再 X 顆星」？ 3) 稀有度完全不隨機？ 4) 新增 4 隻（小象、小恐龍、小鯨魚、彩虹小龍）要換嗎？ 5) 翻牌 8/16/24（阿葉 10-10 已指定，定案）6) 要不要每日時間提醒？
