# 小島同樂廣場（全島合作目標）規格

> 2026-10-11 定案。阿葉原話：「希望有一個互動的方式知道誰也有在玩的排行榜，或許可以每周來個不一樣的挑戰綜合排行分數」。
> 米卡莎（兒少隱私）審 GPT 原案（暱稱＋公開排行＋留言牆）判 FAIL：朋友圈小樣本可從名次推出是誰、「家長協助」不是有效同意。
> 阿葉拍板「全島合作目標可以」＋後端選「Google 試算表＋Apps Script」（不用開新帳號、腳本結構上拿不到訪客 IP）。

## 1. 玩起來長怎樣

- **本週大家一起**：每週一個合作主題，全部玩家的成果加總成一條大進度條，有銅／銀／金三段目標。例：
  - 救援週：大家一起在泡泡救援灣救出 N 隻動物
  - 送貨週：大家一起在彩虹配送站送出 N 件貨
  - 釣魚週：大家一起釣起 N 條魚
  - 讀字週：大家一起答對 N 題（任何遊戲）
  - 收集週：大家一起拿到 N 顆星星
- 達到一段 → 所有人的小島出現慶祝（銅＝彩色氣球、銀＝煙火、金＝島中央金色獎盃雕像一週），貓頭鷹宣布「大家一起做到了！」。
- **「別人也在玩」的感覺**（不用身分）：
  - 進度條會動：打開廣場時從上次看到的數字滾到現在的數字。
  - 「今天島上一共玩了 N 次」（每開始一局 +1）。
  - **加油貼紙牆**：四種固定貼紙（我來玩了！／一起加油！／我救到動物了！／這關好好玩！），點一下聽到內容、再按確認送出；牆上顯示「大家送出的數量」（例：一起加油 ×45），送出時貼紙飛上牆。每台裝置每天最多送 3 張（前端限制）。
  - 自己的貢獻只存本機：「你這週幫忙救了 12 隻！」。
- **入口**：小島 HUD 加一顆「🎪 同樂廣場」按鈕（小孩用、常駐）；打開是全畫面卡片：上方本週主題大圖＋進度條＋三段目標、中間「你幫忙了 N」、下方加油貼紙牆。玩完一局結算時若有貢獻，小字「＋3 救援，已經算進大家的進度囉！」（不跳出、不打斷）。
- **舊週紀錄**：本機成就冊記下每週「大家做到第幾段＋你幫了多少」（只存本機）。

## 2. 隱私（米卡莎建議落實）

- 送到伺服器的只有：`{週次, 主題, 種類, 數量}`。**沒有**裝置 ID、token、暱稱、個人成績、時間軌跡。
- Apps Script 拿不到訪客 IP；試算表只存每週加總。
- 家長頁新增「同樂廣場」區：白話說明送出什麼（上面那行）、不送什麼；開關「參加全島合作」（預設開——資料匿名且不可識別；關了就不送出也不讀取，只是看不到大家的進度）。
- 不顯示任何個人名次或比較；不做排行。

## 3. 技術

- 後端：Google Apps Script 網頁應用程式（執行身分＝阿葉、存取＝任何人），綁一張 Google Sheet「注音小島同樂廣場」：
  - 分頁「主題表」：週次起日、主題 key、標題、銅銀金目標值（阿葉/Claude 可直接改未來幾週）。
  - 分頁「本週」：每週一列（週次、主題、total、plays、cheer_1..4、更新時間）。
  - 儲存格「暫停」：TRUE 時拒收（緊急開關）。
- `doPost`（body 為 text/plain JSON，避免 CORS 預檢）：驗證週次＝台北時間本週、主題＝本週主題（或 kind＝play/cheer_n）、數量 1..30 整數；LockService 鎖住後原子遞增；CacheService 做全域每分鐘上限（例如 1200）。
- `doGet`：回傳本週主題、目標、total、plays、cheer 計數（CacheService 快取 30 秒）。
- 週次：台北時間週一 00:00 換週，前端與後端都用同一個算法（ISO 週＋UTC+8）。主題表沒有填到的週，依固定輪替清單自動帶入。
- 前端：新模組 `js/zhuyin-plaza.js`。貢獻先累加在本機 pending（localStorage），結算時或每 30 秒合併送一次（sendBeacon/fetch keepalive），失敗就留著下次再送；讀取用快取（顯示上次的數字，背景更新）。**後端掛掉或沒網路時遊戲完全照常**，廣場顯示「連不上，等一下再看」。
- 防灌：只能擋到「單次加很大」與「全站爆量」；有人寫程式慢慢灌擋不住——後果只是目標提早達成，已接受。
- 目標值：第一週保守（例如救援週 銅 50／銀 150／金 300），之後依上週實際量的 70–80% 調整（Claude 每週看 Sheet 調，或寫公式自動）。
